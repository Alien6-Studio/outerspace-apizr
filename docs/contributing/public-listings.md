## Public copy

Use product copy for software directories and the MCP-specific variant for the
analysis-server listing. Adapt length to each platform’s actual field limit.

**Product — short (134 characters)**

Python capability compiler for static discovery, scientific experiment tracking and typed REST/MCP interfaces with governed execution.

**Product — standard (451 characters)**

OuterSpace Apizr is a Python capability compiler for static discovery and scientific experiment tracking. Inspect Python code and notebooks, record and compare experiment Runs, and expose selected capabilities through typed REST or MCP interfaces. Capture reproducible evidence where supported by the workflow. Governed execution applies explicit policies and controls; reproducibility depends on retained inputs, dependencies and environment support.

**MCP analysis server — Glama variant (366 characters)**

Python capability compiler with scientific experiment tracking. Its local stdio MCP server provides six read-only tools for static discovery, readiness, exposure planning and experiment history/comparison under operator grants. Three optional delivery tools need separate enablement and permissions. Generated REST/MCP services execute selected functions separately.

The six default tools are `apizr_analyze`, `apizr_readiness`,
`apizr_plan_exposure`, `apizr_experiment_list`, `apizr_experiment_show` and
`apizr_experiment_diff`. History requires `history.read`; source analysis
requires `source.analyze`. The three optional delivery tools have separate
enablement and permission requirements. See the [MCP setup and permissions](../reference/apizr-mcp-server.md).

Generated application MCP servers execute selected functions on client calls.
Governed execution uses explicit policies and supported controls; it is not a
universal sandbox. Recording a Run alone does not guarantee reproducibility.
