# Build and qualify Apizr from source

Use this guide to try the 0.4.6 code before release or test a change in your
checkout. To contribute a PR, follow [Contributing](../about/CONTRIBUTING.md).
For a published package, use [Install Apizr](../getting-started/install.md).

## Install a development wheel

You need Git, uv and Python 3.11–3.15 on macOS or Linux. Start in an empty
directory:

```sh
git clone --branch 0.4.6 --single-branch https://github.com/Alien6-Studio/outerspace-apizr.git apizr-source
cd apizr-source
uv build --wheel --out-dir dist
python3 -m venv ../apizr-evaluation
../apizr-evaluation/bin/python -m pip install dist/outerspace_apizr-0.4.6-py3-none-any.whl
../apizr-evaluation/bin/apizr --version
```

The command should report `outerspace-apizr 0.4.6`. This installs the wheel you
just built. It does not publish a package.

If you need to identify this build later, keep the wheel and the output of
`git rev-parse HEAD`. Build optional plugin wheels from the same checkout.

## Try it outside the source checkout

Copy an example into the evaluation directory and activate its environment:

```sh
cp -R examples/project-config ../apizr-evaluation/project-config
cd ../apizr-evaluation
. bin/activate
apizr inspect project-config/src/calculator.py
```

Run your examples here so the checkout's Python modules do not mask problems
in the installed package. Continue with the
[Quickstart](../getting-started/quickstart.md) to generate and call a service.

## Work with plugins and delivery

Plugins run in separate environments. Follow [plugin installation](../getting-started/install.md#choose-a-plugin-profile)
to install and enable the matching version. Use
[operator permissions](../reference/operator-policy.md) to choose which projects,
registries and signing operations it may access.

For a complete service handoff, follow [delivery](../operations-guide/delivery.md).
It covers building the image, checking it and sending the selected version to
its destination. Installing a plugin does not publish an image or grant access
to credentials.

## Check your change

Use [developer checks](../getting-started/developer-guide/setup.md) for tests,
linting and installed-wheel checks. The
[release procedure](../contributing/releases.md) covers the additional work
needed before a release can be published.
