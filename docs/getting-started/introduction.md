# Introduction

OuterSpace Apizr converts Python functions from scripts and Jupyter notebooks into FastAPI applications and Docker projects.

The development version requires Python 3.8–3.14. Install the checkout with `uv sync --locked` or `python -m pip install .`; a new PyPI release is a separate step.

Start with the [complete workflow](user-guide/apizr.md), the [development setup](developer-guide/setup.md), or the [migration notes](developer-guide/releases.md).
