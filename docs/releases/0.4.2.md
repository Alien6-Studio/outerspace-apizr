# Apizr 0.4.2

## Delivered functionality

- **MCP Delivery:** opt-in status, run and resume for one operator-selected existing
  delivery request, preserving captured authority and the three default read-only tools.
- **Client collections:** deterministic Postman, Bruno and Insomnia exports from
  verified REST bundles, with safe regeneration of owned files.
- **Local onboarding:** `init`, read-only `doctor`, and bash/zsh/fish completion.
- **CI integrations:** forge-neutral `apizr ci`, a GitHub composite Action, and
  structurally validated, self-contained GitLab CI/CD Component source.
- **Homebrew Formula:** core-only installation on qualified Apple Silicon, with
  isolated optional plugins and separate build/runtime dependencies.
- All four coordinated packages and exact internal pins are `0.4.2`. This final
  promotion preserves the runtime behavior of `v0.4.2rc1` and changes no third-party
  dependency versions.

The delivered GitLab Component source does not imply hosted-runtime qualification
or catalog publication. The Alien6 Homebrew tap is not yet published; Intel macOS
Homebrew Tier 3 and Linux Homebrew runtime remain unqualified. OCI behavior follows
generic OCI semantics, without vendor-specific guarantees. Trunx is absent from OSS.

[Publication #231](https://github.com/Alien6-Studio/outerspace-apizr/issues/231)
records its eight original archives, isolated public installation, signed and

Final qualification requires CI, Security, Documentation and all subsystem
workflows on the exact final source, plus hosted and physical Apple Silicon
Homebrew proofs. Publication requires original protected-CI artifacts, all eight
public files matching those bytes, fresh public installation and invocation,
the five managed receipt checks, and the final Homebrew public-source audit.
The public immutable GitHub source must exist before that online audit can run;
issue closure follows the audit. This source update does not integrate master,
deploy documentation, publish the Homebrew tap or publish the GitLab Component.
