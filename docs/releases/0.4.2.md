# Apizr 0.4.2rc2

## Delivered functionality

- **MCP Delivery:** opt-in status, run and resume for one operator-selected existing
  delivery request, preserving captured authority and the three default read-only tools.
- **Client collections:** deterministic Postman, Bruno and Insomnia exports from
  verified REST bundles, with safe regeneration of owned files.
- **Local onboarding:** `init`, read-only `doctor`, and bash/zsh/fish completion.
- **CI integrations:** forge-neutral `apizr ci`, a GitHub composite Action, and
  structurally validated, self-contained GitLab CI/CD Component source.
- **Homebrew Formula:** core-only installation on qualified Apple Silicon, with
  isolated optional plugins and separate build/runtime dependencies.
- **Worker cleanup:** close both parent-side pipes even if process-group termination
  or another pipe closure raises, while preserving failure reporting.
- All four coordinated packages and exact internal pins are `0.4.2rc2`.
  Third-party dependency versions are unchanged.

The delivered GitLab Component source does not imply hosted-runtime qualification
or catalog publication. The Alien6 Homebrew tap is not yet published; Intel macOS
Homebrew Tier 3 and Linux Homebrew runtime remain unqualified. OCI behavior follows
generic OCI semantics, without vendor-specific guarantees. Private commercial product code and integrations are absent from OSS.

## Validation and publication status

`0.4.2rc2` is unpublished and undergoing corrective qualification. Final `0.4.2`
publication is blocked until the corrected runtime and exact protected source
are fully qualified. The [tracking record](https://github.com/Alien6-Studio/outerspace-apizr/issues/232)
retains the failed final-source cleanup run, correction, archive hashes and new
qualification results.

The immutable [`v0.4.2rc1`](https://github.com/Alien6-Studio/outerspace-apizr/releases/tag/v0.4.2rc1)
remains unchanged. RC2 adds deterministic regressions for process-group cleanup
and pipe-close errors to the fixed 25-repetition cleanup series. Neither retries,
skips nor longer timeouts substitute for successful qualification.

Qualification requires CI, Security, Documentation and all subsystem workflows on
the exact source, plus hosted and physical Apple Silicon Homebrew proofs against
the new sdist. This work does not integrate master, deploy documentation, publish
the Homebrew tap or publish the GitLab Component.
