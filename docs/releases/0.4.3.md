# Apizr 0.4.3

## Functionality

- Launch the read-only Apizr analysis server from MCP clients with `outerspace-apizr-mcp`, using the selected project, operator policy and separate plugin store.
- Add the Official MCP Registry descriptor and package ownership metadata for **OuterSpace Apizr**, with local stdio transport and explicit startup paths.
- Declare Glama maintainer ownership. Glama now lists `apizr_analyze`, `apizr_readiness` and `apizr_plan_exposure` with their schemas.
- Coordinate the core, OCI, MCP and Attest packages at **0.4.3**, without changing third-party dependency versions.
