# Apizr 0.4.3

## Functionality

- **MCP client launch:** `outerspace-apizr-mcp` delegates to the existing stdio
  launcher, preserving the operator-selected project, policy and separate
  plugin store. Installation and activation remain explicit.
- **Official MCP Registry:** the `io.github.Alien6-Studio/outerspace-apizr`
  descriptor names **OuterSpace Apizr**, specifies local stdio and the three
  required startup paths, and matches the ownership marker in the MCP package.
- **Glama ownership:** the repository declares its maintainer for administration
  of the public listing. Tool inspection remains a separate Glama operation.
- All four package versions and exact internal pins are `0.4.3`.
  Third-party dependency versions are unchanged.

## Validation

**0.4.3 is not published yet.** Qualification of the coordinated archives is
pending. The source, successful protected release-line run and public-byte
verification will be recorded after those checks complete.

The launcher is exercised from built wheels through the official MCP client on
Linux and macOS. Checks cover both supported protocol modes, discovery and calls
of the three default read-only tools, refusal without analysis authority or an
installed plugin, and preservation of core and activation state. The packaged
ownership marker and descriptor identity are checked together. These development
checks do not establish publication in Glama or the Official MCP Registry.
