# 0.4.6 — development, not published

The official development branch is `0.4.6`. This is a working qualification
record, not a release announcement or publication authorization. Candidate
metadata still inherits 0.4.5 until the coordinated release version change.
Stable master, published archives, tags and publication workflows remain separate.

## Native plugin preparation

Commit [`8dda8c71`](https://github.com/Alien6-Studio/outerspace-apizr/commit/8dda8c711677fc969d8556266d445e4d03723cb5)
adds qualified stable uv 0.13.x and native glibc 2.41 preparation. Development
uses uv 0.13.1, with 0.13.0 and 0.12.0 qualification baselines. The
[preparation policy](../contributing/preparation-qualification.md) defines the
exact matrix and forward refusal policy.

Measured local evidence on 2026-10-14 includes:

| Host | Interpreter / resolver | Result |
| --- | --- | --- |
| macOS ARM | CPython 3.12.13 / uv 0.13.1 | Core resolution; MCP, OCI and Attest prepared outside checkout |
| Debian 13 aarch64, glibc 2.41 | CPython 3.14.8 / uv 0.12.0 and 0.13.1 | Core and all three plugin closures prepared with the unchanged hash lock |
| Glama development image, Debian 13 aarch64 | CPython 3.14.8 / uv 0.13.1 | Exact source SHA, UID 999, three MCP tools and a successful real analysis call through HTTP |

uv does not accept an explicit `manylinux_2_41` CLI triple. The recorded
`native-aarch64-glibc-2.41`/`native-x86_64-glibc-2.41` mode resolves on the
verified native host and preserves PyPA wheel-tag selection. No older libc is
substituted. No source builds, dependency downgrade or implicit activation are
used. Intel MCP's secure locked closure remains unavailable and is qualified by
an explicit compatible-wheel refusal.

The strengthened preparation domain retains **100% line and branch coverage**.
All **105 security mutations** are killed. The broader suite identified stale
Homebrew qualification metadata after the preceding packaging-bound change;
development and frozen publication identities are now handled separately,
with no build-wheel changes or wider publication permission.

The main CI and MCP workflow runs on the exact implementation commit are
[38598348010](https://github.com/Alien6-Studio/outerspace-apizr/actions/runs/38598348010)
and [38598343648](https://github.com/Alien6-Studio/outerspace-apizr/actions/runs/38598343648).
The initial Linux preparation transactions succeeded but their artifact uploader
could not read container-owned private directories. A follow-up qualification
returns only the disposable proof tree to the runner's ownership before upload.
Final qualification status and run identities must be recorded before publication.
