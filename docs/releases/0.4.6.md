# Apizr 0.4.6

Track Python and Jupyter experiments, compare their results in VS Code, and share
a selected prediction through REST or MCP.

## What changes

- **Python tracking:** record an explicit block with `tracking.session` or selected
  calls with `tracking.experiment`. Keep parameters, inputs, metrics and artifacts
  alongside the result.
- **Jupyter:** capture executed cells and use the same experiment history as the CLI
  and Python SDK.
- **VS Code:** inspect scripts and notebooks, browse Runs and compare results from
  the Apizr sidebar.
- **Prediction services:** expose a selected function from a recorded Run through
  REST or MCP, using its model and dependencies without retraining.
- **Scientific providers:** choose recognition providers explicitly; existing
  history remains readable independently of the provider that produced it.

Start with the [notebook quickstart](../getting-started/data-science.md),
[Python tracking](../getting-started/tracking.md) or the
[Academy](../academy/index.md).

## Install or upgrade

```sh
python -m pip install --upgrade outerspace-apizr==0.4.6
apizr --version
```

The [installation guide](../getting-started/install.md) covers uv, pipx, Homebrew
and optional plugins. Keep the core and selected plugins at the same version.

## Compatibility

Python **3.11–3.15** is supported on macOS and Linux. Homebrew is qualified on
Apple Silicon with Python 3.15. Windows and Intel Homebrew runtime are not qualified.
Scientific libraries belong to your workload environment.

## Migration

The historical `--script` / `--notebook` generation pipeline and Python forwarding
modules are removed. Use `apizr inspect`, explicit function selection and
`apizr generate rest` or `apizr generate mcp`.

- [Migration from 0.4.5](migrate-0.4.6.md): commands, configuration and stored records.
- [Removed Python imports](removed-imports-0.4.6.md): canonical replacement APIs.
- [Operator permissions](../reference/operator-policy.md#bind-proof-verification-authority):
  updated grants for managed Attest verification.

## Privacy

Telemetry is optional and off by default. Apizr 0.4.6 provides a local preview
and sends no telemetry. See [telemetry and privacy](../about/telemetry.md).

## Validation

Qualification covers installed packages on Linux and macOS, Python/Jupyter/VS Code
tracking, shared history, REST/MCP calls and changed-artifact refusals.
The [verification guide](../contributing/verification.md) explains how to check
downloaded packages and their provenance.
