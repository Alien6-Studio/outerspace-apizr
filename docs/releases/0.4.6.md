# 0.4.6 — development, not published

The official development branch is `0.4.6`. This is a working qualification
record, not a release announcement or publication authorization. Candidate
metadata still inherits 0.4.5 until the coordinated release version change.
Stable master, published archives, tags and publication workflows remain separate.

## Operator verification authority

Managed Attest `attest`, `publish` and `admit` now bind the operator's reviewed
native verifier (path, version and executable SHA-256), expected signer, trust
directory and public trust content digest. All values must match within one
complete grant. The pure core decision precedes plugin invocation, credential
reads and signing-key access. Native verification uses a bounded private trust
snapshot whose digest is checked before invoking Attest.

Older v1 policies and requests remain readable. Existing grants without the
verification binding refuse these three operations until explicitly reviewed
and extended. Historical receipts/results, read-only verification, image-only
publication, and Git/build/analysis authorization keep their existing contracts.
See the [operator migration instructions](../reference/operator-policy.md#bind-proof-verification-authority).

Focused qualification passes **460 tests**, including managed CLI/API refusals,
MCP and multi-destination delivery. All **118 security mutations** are killed,
including removal of the signing/publication/admission authority binding and
runtime trust-snapshot digest check. Ruff, Pyright, the package architecture gate,
strict documentation build and core wheel/sdist inspection pass. Full suite and
installed delivery qualification are recorded separately when complete.

## Scientific provider and SDK adapter contracts

The [v1 contract](../architecture/scientific-providers-v1.md) separates bounded
source-only recognition from explicitly selected in-process observations. It
reuses canonical experiment values, the existing extension envelope and ordinary
SDK sessions. Core admission rejects source/producer mismatches, undeclared
capabilities, out-of-source locations, runtime claims from static providers and
oversized or non-finite evidence. The architecture inventory prohibits scientific
imports and direct store publication by the provider domain.
