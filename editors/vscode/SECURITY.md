# Security

Report vulnerabilities privately through this repository’s **Security → Report a
vulnerability**, rather than posting source, credentials or experiment data in an
issue. See the [engine security policy](https://github.com/Alien6-Studio/outerspace-apizr/security/policy)
for shared protocol and engine vulnerabilities.

The extension inspects saved files without executing them. Engine/CLI installation
requires a trusted native host and an explicit user action. The bundled descriptor
pins an official engine version/source; workspace files cannot choose the download.
The managed environment is separate from project Python and notebook kernels.
