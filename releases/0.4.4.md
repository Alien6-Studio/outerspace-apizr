# Apizr 0.4.4

**0.4.4 is published and verified.** Install it from PyPI or the
[Alien6 Homebrew tap](https://apizr.outerspace.sh/getting-started/install/#homebrew-on-apple-silicon).
The core and optional OCI, MCP and Attest plugins are all available at 0.4.4.

## What you can do with this release

<span id="existing-confirmed-gap-change-expected-evidence"></span>

- **Share a service description** with deployment tools, without running your code.
- **Connect that description to the container you built**, so other tools can
  check they are using the right version.
- **Read delivery results from other languages**, using the provided JSON Schemas.
- **Publish to a new container destination** with improved support for
  authenticated registries.

See [repository exposure and exports](https://apizr.outerspace.sh/getting-started/user-guide/exposure/),
[OCI service images](https://apizr.outerspace.sh/reference/oci-service-plugin/) and
[external governance](https://apizr.outerspace.sh/reference/external-governance/) for the commands and
integration workflow. New to Apizr? Start with the [Quickstart](https://apizr.outerspace.sh/getting-started/quickstart/).

## Upgrade

Follow [Install Apizr](https://apizr.outerspace.sh/getting-started/install/) using version **0.4.4**.
If you use plugins, update the selected profiles to the same version as the core.
Existing generated services have their own runtime dependencies.

<span id="contracts-and-compatibility"></span>

## Compatibility and limitations

Existing v1 schema IDs, serialization and stored results remain compatible.
Export is an additive CLI/Python API and reuses existing bundle documents.
Unknown schemas and fields are refused. A historical build without the required
lineage cannot satisfy the optional bundle-to-build check.

Apizr remains an independent Python tool. Your deployment platform owns
organizational approvals and runtime access control; a successful technical
admission does not replace those decisions.

## Tools using Apizr

- **[Trunx](https://trunx.io/)** — a private registry for software packages and
  container images. It uses Apizr 0.4.4 to publish REST and MCP services within its
  deployment approval workflow.

The [integration guide](https://apizr.outerspace.sh/reference/external-governance/) explains how to
share service descriptions and delivery results with your deployment platform.
